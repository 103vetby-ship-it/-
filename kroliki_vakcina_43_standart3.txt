<h2 class="clinical-title">На каких трёх принципах строится защита декоративных кроликов?</h2>
<p class="voice-answer-nugget">
Ассоциированная вакцина для декоративных кроликов защищает сразу от миксоматоза и вирусной геморрагической болезни (ВГБК) в одной инъекции. Прививку делают здоровым кроликам с 5–7 недель при массе от 500 г без предварительной слепой дегельминтизации, а ревакцинацию проводят каждые 6–12 месяцев с контролем холодовой цепи +2…+8 °C.
</p>
<ul class="clinical-list">
<li>
<h3>Антигенный состав: Myxoma virus + RHDV</h3>
<p>Живой аттенуированный штамм вируса миксомы защищает от отёчно-узелковой инфекции с летальностью до 90–100%. Инактивированный калицивирус геморрагической болезни (RHDV1, в современных формулах также RHDV2) предотвращает молниеносный некротический гепатит. Комары заносят миксоматоз через окна; вирус ВГБК попадает с сеном, зеленью и на обуви.</p>
</li>
<li>
<h3>Возраст старта, вес и материнские антитела</h3>
<p>Клинически здоровые крольчата с 5–7 недель при массе не менее 500 г. При очень раннем старте от вакцинированной матери материнские антитела могут снизить ответ на компонент миксоматоза — врач назначает бустер. Ревакцинация: каждые 6–12 месяцев в зависимости от типа формулы.</p>
</li>
<li>
<h3>Без слепой дегельминтизации и Rabies только по показаниям</h3>
<p>По BSAVA домашним кроликам не проводят профилактическую дегельминтизацию «вслепую»: гельминты редки, лишняя нагрузка не нужна. Врач оценивает аппетит, стул и температуру дома (норма 38,5–39,5 °C). Антирабическая вакцина — только при выезде/выставках, с 12 недель, раздельно, т.к. местные реакции у кроликов встречаются чаще.</p>

const textSprite = new THREE.Sprite(new THREE.SpriteMaterial({ map: textTexture, transparent: true, depthTest: false, opacity: 0.95 }));

textSprite.position.set(0, -0.85, 0);
pawGroup.add(textSprite);
scene.add(pawGroup);

const pPos = new Float32Array(80 * 3);
for(let i = 0; i < 80 * 3; i++) { pPos[i] = (Math.random() - 0.5) * 12; }
pGeo.setAttribute('position', new THREE.BufferAttribute(pPos, 3));
const pMesh = new THREE.Points(pGeo, new THREE.PointsMaterial({ size: 0.04, color: 0xF5DEB3, transparent: true, opacity: 0.9, blending: THREE.AdditiveBlending }));
scene.add(pMesh);
const clock = new THREE.Clock();
const animate = () => {
requestAnimationFrame(animate);
const t = clock.getElapsedTime();
edges.rotation.y += 0.005;
edges.position.y = Math.sin(t * 1.2) * 0.15;
pawGroup.rotation.y = edges.rotation.y;
pawGroup.position.y = Math.sin(t * 1.2) * 0.15;
pMesh.rotation.y = t * 0.08;
pMesh.position.y = Math.sin(t * 0.5) * 0.2;
renderer.render(scene, camera);
};
animate();
